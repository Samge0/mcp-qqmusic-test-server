API 文档

使用 search_music 函数搜索音乐

search_music 主要功能

参数

keyword 字符串，必需 - 搜索关键词或短语
page 整数，可选 - 分页页码（默认值：1）
num 整数，可选 - 返回结果的最大数量（默认值：20）

返回值

返回包含歌曲信息的对象数组，每个对象包含以下属性：

  • id - 歌曲ID
  • mid - 音乐ID
  • name - 歌曲名称
  • pmid - 播放音乐ID
  • subtitle - 歌曲副标题
  • time_public - 发布时间
  • title - 歌曲标题

示例响应

[
  {
    "id": "123456",
    "mid": "001Qu4I30eVFYb",
    "name": "七里香",
    "pmid": "",
    "subtitle": "",
    "time_public": "2004-08-03",
    "title": "七里香"
  }
]

常见问题

快速解答您的疑问

MCP 是什么？
MCP（Modular Control Protocol，模块化控制协议）是一种用于在不同系统之间进行通信和控制的标准化协议。本项目使用 MCP 协议来提供音乐搜索功能。
如何安装 uv 包管理器？
uv 是一个快速的 Python 包管理器。您可以从 GitHub - uv 获取安装说明。
这个项目可以商用吗？
这个项目仅供测试和学习目的使用。QQ音乐的相关服务请遵守其官方使用条款。
搜索结果的数量有限制吗？
是的，您可以使用 num 参数控制返回结果的数量，默认值为 20。
